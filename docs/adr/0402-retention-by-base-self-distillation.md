# 0402 — Dataset d0.2: retention by base self-distillation, gateway traces, concise numeric answers

- Status: accepted
- Date: 2026-10-24

## Context

The `p1-ml` pilot (120 steps on `d0.1`) improved tool use and grounding but regressed classic suites: FPB −6.6, FiQA-SA −5.7, FinQA −6.0, TAT-QA −3.0 points, above the release gate's 3-point limit. Its outputs show two causes. (1) The classic-task samples taught a phrase-bank voice ("Short take on the sentiment: … This is a read of the wording only") and a "Step by step: … So the answer is **X**" numeric format that differ from the formats the evaluation prompts ask for, and the tweet sentiment source is ~65 % neutral, which matches the pilot's drift towards "neutral" on FPB. (2) The general-retention slice used smoltalk's own answers, written by other models, so even retention samples pulled the model away from the base distribution. The held-out `tool_use` traces also came from the fake executor rather than the real gateway.

## Decision

Dataset **`d0.2`** (`ml/configs/data/d0.2.yaml`, `d0.1` stays reproducible for the pilot):

- **Self-distilled retention** (`lab data distill`, `candela_lab/data/distill.py`): prompts from permissive training splits — FinQA, TAT-QA (arithmetic/count) and ConvFinQA first questions, financial-tweet sentiment and topic, smoltalk constraint/rewrite instructions — are answered by the **frozen QAT base** (greedy, thinking off). Answers are kept only when the number matches the gold answer (1 % tolerance, the eval's rule), the label matches the gold label, or (general prompts) generation ended before the token limit; outputs with special tokens are dropped. Sentiment prompts are balanced across the three labels. About 60 % of the prompts use the evaluation suites' instruction wording on training-split content, the rest varied phrasings, so the adapter keeps the base's format compliance without seeing evaluation items. Every prompt is 13-gram decontaminated before generation and again at build time.
- ConvFinQA dialogues (which the base answers poorly, so distillation would keep too few) keep gold answers in a concise format: at most two calculation lines, then `Answer: <number>`.
- **Traces**: 6 000 conversations and the 300 held-out evaluation conversations are regenerated through Candela Lab's own gateway instance (`ml/scripts/gateway-ml.sh`, 127.0.0.1:8730/8739, own SQLite file, shared snapshot). The mix takes 4 500 trace turns.
- Mix (≈ 9.75 k samples): traces 4 500, agentic finance 1 000, function calling 800, numeric 1 700 (82 % distilled), classic labels 750, general retention 1 000.

## Consequences

- Retention answers carry the base's own style and occasional errors that the gold check cannot see; the adapter's departure from the base on these prompts is small by construction.
- Distillation costs ≈ 2–3 h of GPU time on the shared machine (guarded, resumable by chunk).
- The published model card states that a share of the training answers was generated by the base model.

## Alternatives considered

- More templated gold answers in more phrasings: still an off-distribution voice for the base and still label-skewed.
- Dropping classic tasks entirely: removes the forgetting signal the pilot showed was needed.
- Distilling from a larger teacher: not available locally within the memory budget, and licenses of hosted teachers would complicate redistribution.
